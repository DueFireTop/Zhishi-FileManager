# 🐷 知时·文件管理

**把零散文件整理成清楚、有层次的个人资料库。**

知时·文件管理是一款面向 Windows 的本地资料管理软件。用分类、标签、收藏和备注整理学习文档、论文与项目资料，搭配粉色小猪风格界面，让日常归档轻松一点。

[下载最新版本](https://github.com/DueFireTop/Zhishi-FileManager/releases/latest) · [查看更新记录](https://github.com/DueFireTop/Zhishi-FileManager/releases) · [反馈问题](https://github.com/DueFireTop/Zhishi-FileManager/issues)

> 本仓库用于发布安装包与版本更新。日常资料管理在本地完成；检查和下载更新需要联网。

## ✨ 主要功能

| 功能 | 说明 |
| --- | --- |
| 多级分类 | 按树形层级选择分类，支持新增、重命名、移动与删除 |
| 分类地图 | 通过展开式分类地图查看结构，悬浮分类卡片即可进行管理 |
| 文件与文件夹入库 | 支持多文件、文件夹导入及拖入，文件夹层级自动转为分类 |
| 标签与检索 | 使用名称、分类、标签等条件筛选资料，标签随当前分类显示 |
| 资料信息编辑 | 管理名称、标签、备注与收藏，编辑后点击卡片外部自动保存 |
| 批量操作 | 通过选择框全选、取消全选，批量更换分类、移入回收站及拖动归类 |
| 文件预览 | 主动打开 PDF、DOCX、图片、Markdown 与常用文本的预览 |
| 收藏与最近记录 | 直接收藏资料，从首页“更多”查看最近上传与最近打开记录 |
| 回收站 | 恢复资料或清空回收站，支持相关右键操作 |
| 撤回操作 | 撤回本次打开软件期间最近 20 次受支持的修改，批量操作计为一步 |
| 可调整布局 | 调节侧边栏与资料卡片宽度，标签根据侧边栏宽度自动换行 |
| 公告与更新 | 查看版本公告、检查更新，未读公告显示红点 |

保存资料信息后会保留当前分类，方便连续整理。资料卡片不自动生成缩略图，需要查看内容时点击“预览资料”。

## 💻 下载与安装

适用于 Windows 10 / 11，使用 Windows PowerShell 5.1 与 WPF 运行。

1. 打开 [最新版本下载页](https://github.com/DueFireTop/Zhishi-FileManager/releases/latest)。
2. 在 **Assets** 中下载 `Zhishi-FileManager-Setup-v版本号.exe`。
3. 关闭正在运行的知时·文件管理，运行安装包，按照提示完成安装。
4. 从桌面或开始菜单中的“知时·文件管理”快捷方式启动。

例如，v1.3.1 对应安装包为 `Zhishi-FileManager-Setup-v1.3.1.exe`。同页的 `.exe.sha256` 是校验文件，无需安装。下载时选择安装包，而不是 `Source code` 压缩包。

升级可直接按原路径覆盖安装，现有资料库与设置继续沿用。

## 📁 开始整理资料

1. **选择分类**：选中现有分类，或在“我的分类”的管理界面创建分类。
2. **导入资料**：选择文件或文件夹，也可直接拖入软件，再确认入库信息。
3. **补充信息**：为资料添加标签、备注或收藏，便于后续查找。
4. **批量整理**：勾选多份资料，批量更换分类、移入回收站，或一起拖到目标分类。

导入文件夹时，选中的普通分类作为父分类，文件夹及其子文件夹按原层级建立分类。在“全部资料”或“未分类”下导入时，文件夹作为顶级分类。单次入库最多 500 份资料。

## 🔄 检查与安装更新

更新源已内置为本仓库，无需自行填写地址。

打开软件内的 **“公告与更新” → “检查更新”**，即可查看新版本说明；“更新设置”中可调整是否在启动时自动检查。

| 更新类型 | 处理方式 |
| --- | --- |
| 同一大版本，例如 1.3.1 → 1.3.2 | 在应用内下载、校验并安装，完成后重新打开软件 |
| 跨大版本，例如 1.x.x → 2.x.x | 打开 GitHub 发布页面，由用户下载并运行新版安装包 |

应用内更新下载的安装包目前会保留，不会安装后自动删除。更新相关文件位于 `%APPDATA%\ZhishiFileManager\updates`，更新日志位于 `%APPDATA%\ZhishiFileManager\update.log`。

也可以随时从 [Releases](https://github.com/DueFireTop/Zhishi-FileManager/releases) 下载安装包，关闭软件后手动覆盖安装。

## 🗂️ 数据保存与备份

软件将导入的文件**复制到资料库**。入库前的源文件保留；之后在软件内重命名资料，会同步重命名资料库中的文件副本。

默认资料库位于 Windows 的“文档”目录下的 `知时文件资料库` 文件夹。可通过 **“资料库与存放目录”** 查看目录、切换资料库或迁移资料库。

| 内容 | 用途 |
| --- | --- |
| `library.json` | 资料记录、分类层级、标签、备注、收藏及回收站状态 |
| `library.json.bak` | 上一次保存前的资料记录备份，不是完整文件备份 |
| `files` 文件夹 | 实际入库的文件副本，按记录编号分别存放 |
| `%APPDATA%\ZhishiFileManager` | 软件设置、启动诊断与更新相关文件 |

**备份时先关闭软件，再完整复制资料库目录，包含 `library.json` 和整个 `files` 文件夹。** 若需同时保留软件设置，也可备份上述 AppData 目录。恢复时通过“切换资料库”选择备份目录。

请在软件内进行文件重命名，避免直接修改资料库内部的编号目录或移动文件而导致记录失效。软件卸载不会自动删除资料库与用户设置。

“移入回收站”保留资料库中的文件；**“清空回收站”会永久删除对应的入库文件，不能通过撤回恢复**，不会删除入库前的源文件。

## 👀 预览说明

- **PDF**：支持分页预览，加密或损坏的文件可能无法读取。
- **DOCX**：以正文与表格文字为主，不还原原始分页、图片和复杂排版。
- **Markdown**：提供渲染阅读视图，支持常用排版语法，不等同于 Typora 的全部功能。
- **图片与常用文本**：可主动打开预览；其他格式可通过“打开资料”调用系统关联程序。

旧版 Office 格式及复杂文档的查看效果取决于文件格式与本机软件环境。

## ⌨️ 常用快捷键

在资料列表中使用以下快捷键；文本输入框中的快捷键仍按文字编辑规则处理。

| 快捷键 | 操作 |
| --- | --- |
| `Enter` | 打开当前资料 |
| `F2` | 重命名当前资料 |
| `Delete` | 移入资料库回收站 |
| `Ctrl + C` | 复制资料完整路径 |
| `Ctrl + Z` | 撤回上一步受支持的资料操作 |
| `F5` | 刷新资料与文件状态 |
| `Shift + F10` | 打开当前项右键菜单 |

## ❓ 常见问题

### 安装时提示软件仍在运行怎么办？

先关闭软件窗口，等待进程退出后重试。如窗口已关闭但仍提示占用，可保存其他工作后重启电脑，再运行安装包。

如需通过任务管理器处理，请先查看进程的“命令行”，仅结束指向本软件安装目录、运行 `Bootstrap.ps1` 或 `FileManager.ps1` 的进程。其他软件也可能使用 PowerShell，请勿统一结束所有 `powershell.exe`。

### 打开资料并编辑，会修改原文件吗？

“打开资料”打开的是资料库中的副本。保存修改会更新该副本，不会同步修改入库前的源文件。

### 为什么回收站中的资料还占空间？

移入回收站只改变资料状态，文件保留以便恢复。清空回收站才会永久删除对应副本并释放其占用空间。

### 检查更新失败怎么办？

先确认网络可以访问 GitHub，稍后重试；也可直接从 Releases 下载并手动安装。反馈时可附上 `update.log` 中与失败相关的内容。

### 软件无法启动时如何排查？

可查看 `%APPDATA%\ZhishiFileManager` 中的 `startup.log` 与 `last-error.log`；也可运行安装目录内的“启动诊断.cmd”查看错误。正常使用请从软件快捷方式启动。
